How the Speed Test Works

  1. 1

    Ping & jitter

    20 tiny requests measure round-trip time. Ping is the median; jitter is the average change between consecutive samples.

  2. 2

    Download

    Four parallel streams pull data for about 8 seconds. The first 1.5 s (TCP ramp-up) is excluded, then bytes ÷ time gives Mbps.

  3. 3

    Upload

    Three parallel POST streams push data for about 7 seconds. Progress events count bytes sent; the warm-up is excluded too.

  4. 4

    Result

    Everything shown is measured from real transfers. If a stage fails, it is marked unavailable, never guessed.

About PulseOrbit

PulseOrbit is an open-source, static website: plain HTML, CSS and JavaScript with a Three.js scene. There is no backend, no account, no tracking and no API key. Your history never leaves your browser.

Test traffic goes to Cloudflare Speed Test. The endpoints are configurable in js/config.js, so you can point the tool at your own server.

Technical limitations

  • Browser tests are estimates: they reflect the path to one test server, not your whole ISP.
  • Wi-Fi quality, other devices, VPNs, extensions, and browser throttling can lower results.
  • Very fast links (multi-gigabit) may be limited by the browser or server before the network.
  • Upload is counted by browser progress events, which can slightly overstate results on very slow links because of send buffers.
  • GitHub Pages cannot host an upload endpoint, so upload relies on an external, CORS-enabled service.

Frequently Asked Questions

Why is my result different from other speed tests?

Each service uses a different server, number of connections and averaging method. Results vary by a few percent to a lot depending on distance to the server and current congestion.

What is jitter?

Jitter is how much latency varies from one request to the next. Low jitter matters for video calls and gaming. PulseOrbit reports the mean absolute difference between consecutive ping samples.

Is the data real?

Yes. Nothing is simulated. If an endpoint is unreachable or blocked, the affected metric shows as unavailable with the reason.

How much data does a test use?

It depends on your speed, because tests run for a fixed time. A fast connection can transfer several hundred megabytes in total, so be careful on metered plans.

Why is upload unavailable?

Upload needs an endpoint that accepts POST requests and allows cross-origin access. If the configured one is unreachable or removed, the upload card says so. See the README to configure another.

Does it store my data?

Only your last 10 results and your theme choice, in this browser's localStorage. You can clear the history at any time.
